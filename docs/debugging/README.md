# Catatan debug

Satu berkas per masalah, bernama `YYYY-MM-DD-judul-singkat.md`, mengikuti format di bab 17 spesifikasi (`docs/pentahoot-spec.html#debugging`). Catatan ditulis untuk bug yang butuh lebih dari satu jam, yang muncul di staging atau production, atau yang penyebabnya tidak terduga. Pelajaran yang mengubah aturan juga masuk ke spesifikasi dengan ID (W8).
